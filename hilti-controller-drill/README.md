# Hilti Controller Drill

Juego móvil (PWA-ready web app) para aprender la **cultura Hilti**, conceptos de **finanzas / controlling** y el rol de **Finance Controller en Panamá**.

## Cómo jugar

1. Abre la caja roja
2. Elige una misión: Cultura, Finanzas o Controller Panamá
3. Toca la respuesta correcta y lee el tip
4. Completa ≥70% para “llenar” la caja roja (progreso en localStorage)

## Desarrollo

```bash
cd hilti-controller-drill
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Stack

- Vite + React + TypeScript
- Framer Motion
- Diseño mobile-first con branding inspirado en Hilti (rojo caja / herramientas)

## Nota

Contenido educativo de onboarding personal. No es un producto oficial de Hilti.
