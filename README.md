# Hilti Controller Drill

Juego móvil web para onboarding al rol **Finance Controller en Hilti Panamá**.

## Arranque rápido

```bash
cd hilti-controller-drill
npm install
npm run dev
```

Abre la URL local en el teléfono o en DevTools → modo móvil.

## Qué incluye

- **Cultura Hilti** — purpose, valores, Care & Perform, cliente directo
- **Finanzas Controller** — controlling, variances, P&L vs cash, forecast, working capital, KPIs
- **Controller Panamá** — partner del negocio, cierre, FX/reporting, integridad

Temática de caja roja / herramientas. Progreso guardado en el navegador.
